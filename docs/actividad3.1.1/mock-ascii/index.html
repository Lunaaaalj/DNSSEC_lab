Activity 3.1.1 · Social engineering
Five terminals, one set of ASCII animations

Every prototype runs the same four slides and the same live ASCII scenes, drawn character by character on a canvas. Only the terminal around them changes.

  • Cover: a bust assembles from characters, with a glowing keyhole where trust lives.
  • Phases (press → five times): radar sweep over open sources → a forged IT badge decoding → the message in flight → a key opening the lock → the lock closing with the controls typed out.
  • Case: packet stream behind the simulated email, with indicators flagged one step at a time.
  • Between slides and phases, the old scene dissolves into the new one cell by cell, with a short glitch band only where there is ink; slide text fades out softly and the new text rises in a staggered sequence.
  • Defense: press the toggle and a wall builds; the same message shatters instead of opening the lock.
